# Frontend (React)

Este directorio contiene el código de la aplicación cliente desarrollada con React. Es la interfaz de usuario que interactúa con el backend de FastAPI.

## Configuración y Dependencias

Sigue estos pasos para configurar y levantar el servicio frontend.

### Rutas y Preparación

1.  **Navega a este directorio:**
    ```bash
    cd Proyecto-Final-FastAPI-Frontend
    ```

2.  **Instala las dependencias de Node.js:**
    ```bash
    npm install
    # O si usas yarn:
    yarn install
    ```

### Inicio del Servicio Frontend

Desde este directorio (`Proyecto-Final-FastAPI-Frontend`), ejecuta:

```bash
npm run dev
```
Este comando iniciará el servidor de desarrollo de React, generalmente en `http://localhost:5173`.
